# gz-skills v0.6.0 baseline assessment

Checked October 11, 2026 for the scoped starter bundle update following the
initial template release. Adopt v0.6.0 instead of v0.5.0; the starter's next
version is 0.2.0 under its 0.x additions policy. No other dependency update is
included, and no claim of full toolchain freshness is made.

## Compatibility and preservation

The upstream Python bundle CLI floor changes to Python 3.13; starter Python
3.14.8 satisfies it. Native plugin use does not require that CLI. We reference
immutable upstream sources and vendor no skills or runtime dependencies.

The reviewed upstream maintenance skill explicitly preserves approved starter
policy over its default heavy profile. Retain Python 3.14, Ruff/complexipy/Lizard
and the starter's Xenon/Radon retirement. Do not infer lite/heavy selection,
invoke project setup or install additional default profile tools from this pin
change. Application settings and project authorities remain project-owned.

Python 3.14 opportunities over 3.13 were assessed using the starter guide:
annotation introspection, bounded executor submission, compression, Path copy/move
and template strings have no consumer in this metadata/guidance update. Defer
them; no helper code or runtime behavior needs modernization for this release.

Scope includes bundle release/SHA, both catalogs, template/package version,
uv-managed lock refresh and current guidance. SP, disabled SP-BP, runtime,
development tools, CI actions and machine-global plugins are outside this update.
There is no Python package dependency change requiring a new package audit.

Existing managed records differ and require deliberate reconciliation; the
helper's refusal to overwrite remains intentional. Keep prior pins and the
immutable v0.1.0 release for rollback. The existing public-seam adoption tests
verify version/SHA recording, profile/app-file preservation and catalog agreement.
