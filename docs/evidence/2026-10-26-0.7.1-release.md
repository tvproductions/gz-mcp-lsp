## Verification

Observed on Windows with managed CPython 3.14.10 / uv 0.13.5 and independent
3.12.16 X-Plane standalone execution:

- Locked all-group sync, resource generation and all four routine hooks pass;
  39 real adoption tests remain unchanged.
- All 29 explicit analyzer regressions pass, including 16 new consumer tests.
  Fixture-answer adapters prove consumer failure handling, not scorer correctness.
- C901 passes at 20. Lizard's unchanged 20/20/20 contract reports 147 functions,
  maximum 16, overall mean 3.435374149659864, no errors/violations.
- Both X-Plane positive/negative tool probes pass with Ruff 0.17.3. The cognitive
  fixtures are Python 3.14-specific and do not certify X-Plane or Python 3.12 scoring.
- New consumer modules: Interrogate 91.7% (default minimum 80); Vulture no
  findings; Bandit no findings. Existing reviewed source findings from the 0.7.0
  receipt remain historical and are not relabeled as a clean whole-tree result.
- Consumer statement coverage is 91.6% and branch coverage 76.9%; no percentage
  gate was invented. Positive real-engine installation/CLI paths remain pending.
- Hash-enforced audit of exact uv exports: all 74 standard and 75 X-Plane
  registry distributions, no known vulnerabilities and no skipped packages.
  The auditor warns that --no-deps is redundant with hashes; no second resolver
  or automatic fix was used.
- deptry and the actual CLI-to-wrapper import contract pass. The pure stdlib
  consumer requires no new runtime dependency or 3.14 concurrency machinery;
  grammar fixtures intentionally exercise CPython 3.14 template syntax.
- Source-independent build, bundle/both catalogs and isolated installed
  distribution checks are required on the final candidate. The sdist must include
  the new tools and JSON fixtures; the wheel still contains no development tools.

The unchanged production helper and Cosmic Ray compatibility retain the bounded

Source/fixture hashes are in the JSON companion. Preserve failed cognitive
