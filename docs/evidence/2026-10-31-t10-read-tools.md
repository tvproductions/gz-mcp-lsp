## Behavior and test-first evidence

The MCP catalog now contains exactly seven read tools, all annotated read-only,
non-destructive and closed-world. Rename/edit, including their previews, remain
unregistered. The existing R0 transaction-construction trap now covers all seven
actual-ty reads, unchanged source bytes, absent state storage and child reaping.

Initial tests failed on missing public operations, the four-tool catalog and absent
workspace symbol resolution negotiation. The implementation added semantic methods,
SDK wrappers and workspace.symbol.resolveSupport for location.range. A pure
symbol_values.py module owns symbol-shape validation and normalization; Navigation
retains operation leases, protocol requests, scope marking and result envelopes.

Document symbols preserve explicit hierarchy and separate full/selection ranges.
Flat symbols remain flat with selection_range=null. Workspace search retains
duplicate names, numeric coordinate order and URI-only unresolved locations.
resolve=true is accepted only when the server advertises its resolver; opaque
original data is forwarded unchanged. Already ranged symbols need no resolve call.
Range availability is reported as resolved; it never makes a full declaration range
an identifier selection. Returned scope labels do not cause external source reads.

A further regression reproduced a resolution-order error: adding ranges can change
sorting order without changing symbol identity. Compare each response with its own
original name/kind/URI before sorting. Tests now cover that case, changed-identity
rejection and stale results after concurrent saved-file changes in all three tools.
Malformed symbols, unsupported capabilities, strict SDK inputs and result limits
remain explicit errors; no silent truncation or guessed coordinates.

These choices follow the LSP definitions for
[document symbols](https://github.com/microsoft/language-server-protocol/blob/gh-pages/_specifications/lsp/3.17/language/documentSymbol.md)
and [workspace symbols/resolve](https://github.com/microsoft/language-server-protocol/blob/gh-pages/_specifications/lsp/3.17/workspace/symbol.md).
They introduce no additional semantic tools or general LSP interface.
